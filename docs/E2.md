## Description:

Cette partie concerne la gestion du projet. Tous les documents requis sont dans le dossier E2/.    
- les attendus du rendu E2 détaillés dans le fichier E2.odt
- les documents demandés  

Le choix de l'architecture générale ce faisant à ce stade, j'y ai joint la structure la concernant.  

## Architecture:

Le langage de programmation de ce projet est python. Tous les dossiers sont des modules python (présence des fichiers `__init__.py` dans chacun d'eux) et les scripts sont prévus pour être exécutés depuis la racine du projet. J'ai opté pour poetry pour la gestion de l'environnement mais c'est facultatif.  
Toutes les librairies nécessaires sont listées dans les fichiers poetry.lock, pyproject.toml, requirements-airflow.txt et requirements-app.txt. Airflow et SQLAlchemy fonctionnent avec des versions de python incompatibles (<3.11 pour le premier et 3.12 pour second) imposant deux requirements différents.   

Le .env contient toutes les variables d'environnement. Elles sont chargées dans le fichier config/config.py (module python), pouvant ainsi être importées facilement dans chaque script.  
Certaines étant renseignées automatiquement, par précaution une copie (.env.last_run), en est faite avant.  
Afin de connaître le contenu du .env et de le joindre au dépôt git, le fichier .env.template en est le miroir sans les secrêts. 

Tout le projet est conteneurisé avec Docker, orchestré avec Airflow et exposé via Ngrok associé à Nginx.  
Les dossiers dags/ (les scripts d'orchestration), logs/ et plugins/ sont propres au fonctionnement d'Airflow.  
Le fichier ngrok.yml contient la configuration de Ngrok. A l'instar du .env, il en existe un miroir, le ngrok.yml.template. Il n'est cependant pas nécessaire d'y toucher, les informations sensibles sont dans le .env et injectées par le setup_infra.sh. 
Le fichier nginx.conf définit les différentes redirections:
- la racine / pour le catalogue de données (port 8501 sinon)
- airflow/ pour l'orchestration (port 8080 sinon)
- api/ et api/docs pour l'API (port 8000 sinon)
- mail/ pour la messagerie (port 8025)  

Dernier fichier de configuration garage.toml. Comme pour ngrok.yml, il en existe un miroir, le garage.toml.template auquel il n'est pas nécessaire de toucher. Le seul secret qu'il contient est une clé hexadécimale pour le rpc_secret (Remote Procedure Call). Elle est générée et injectée par le setup_infra.sh.

## Le déployeur setup_infra.sh

Ce script permet d'automatiser presque intégralement le déploiement du projet (voir la procédure ). Les principes fonctions:  
- contruction des images et démarrage des conteneurs une fois leur configuration prête
- création des dossiers dags, logs et plugins pour Airflow avoir restitution des droits à l'utilisateur
- mise à jour des requirements
- création des bases de données (Airflow et dwh E5/E6) et configuration via leur fichier sql (schémas, tables, rôles, droits)
- création des garage.toml et ngrok.yml par copie de leur template et injection automatique des variables générées 
- configuration complète de Garage (capacité, layout, clés, buckets, droits) et copies des informations nécessaires aux connexions dans garage_dl.txt

## Les services Docker

Les différents services sont répertoriés dans le docker-compose.yml. Les installations supllémentaires sont dans deux dockerfiles: 
- Dockerfile pour l'image Airflow avec python 3.11 et ses requirements 
- Dockerfile.app pour l'image python 3.12 (requise par SQLAlchemy entre autre), des installations supplémentaires (notamment chromium pour playwright) et ses requirements 

Les services:
- garage (datalake)
- db_postgres (bdd PostgreSQL)
- db_mongo (bdd MongoDB)
- airflow_init (création du user de connexion Airflow)
- airflow_webserver (interface web de l'orchestration)
- airflow_scheduler (compute de l'orchestration)
- streamlit_catalog (interface web streamlit pour le catalogue de données)
- fastapi_api (API)
- nginx_proxy (reverse proxy pour le redirection des ports utilisés)
- ngrok (le tunnel)
- mailhog (simulateur de messagerie mail pour l'alerting)
